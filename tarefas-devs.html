Recuperar Senha
Fluxo completo de "Esqueci minha senha". Hoje não existe — usuário que perde a senha não consegue entrar.
APIUI
Alta
🖥️ Como vai funcionar
  • Link "Esqueci minha senha" na tela de login, bem discreto abaixo do botão
  • Tela /esqueci-senha: só um campo de e-mail + botão. Mensagem neutra: "Se esse e-mail existir na nossa base, você receberá um link em instantes"
  • E-mail com visual bonito do AniHype — não o e-mail genérico padrão

💡 Ideia de melhoria

O e-mail de recuperação pode ser a primeira impressão do AniHype para alguém que sumiu por um tempo. Vale a pena caprichar no visual com o logo e uma mensagem de boas-vindas de volta.

🎨 Indicador de força da senha

Barra colorida abaixo do campo: Fraca (vermelho) → Boa (amarelo) → Forte (verde). Simples de implementar e melhora muito a experiência.

Docker Compose + Deploy
Colocar o AniHype em um endereço real na internet. Sem isso, só funciona na máquina de quem desenvolveu.
INFRA
Crítico
🌐 O que precisa existir
  • Um endereço real: anihype.com.br ou subdomínio de teste
  • HTTPS — sem isso o navegador bloqueia o site hoje em dia
  • Ambiente de staging (teste) separado de produção
  • Deploy fácil: idealmente subir com um comando só
  • Banco de dados persistente — não perder os dados ao reiniciar
  • Logs acessíveis para ver erros quando algo quebrar em produção
💡 Recomendação de serviço

Para começar rápido: Railway.app — conecta no GitHub e faz deploy automático, não precisa saber de servidor. Para reduzir custo depois de crescer: VPS na Hetzner (~R$25/mês).

⚠️ Prioridade máxima

Sem deploy, o time não consegue testar com usuários reais. Todas as outras tarefas dependem disso estar funcionando.

Denúncia + Moderação de Comentários
Forma de manter a comunidade saudável. Usuários denunciam, admins revisam.
APIUI
Média
🖥️ Como vai funcionar
  • Botão de 3 pontinhos (...) em cada comentário — ao clicar aparece opção "Denunciar"
  • Modal simples com opções de motivo: "Spoiler sem aviso", "Conteúdo inadequado", "Spam", "Outros"
  • Confirmação: "Obrigado! Sua denúncia foi registrada."
  • No painel admin: aba Moderação com lista de comentários denunciados
  • Cada item mostra: o comentário, quem denunciou, o motivo e quando

  • Comentário removido por mod aparece como "[Comentário removido pela moderação]" — não some
💡 Melhoria futura

Auto-moderação: se um comentário receber 5 denúncias fica automaticamente oculto até revisão. Evita que conteúdo ruim fique visível enquanto o admin está ocupado.

Média
🎨 O que melhorar
  • Skeleton loading em todas as páginas — ao invés de tela em branco, mostrar "fantasmas" cinzas do layout enquanto carrega

Uma busca que encontra tanto animes quanto usuários. Hoje a busca só funciona dentro do catálogo.
APIUI
Alta
🖥️ Como vai funcionar
  • Ícone de lupa no header — ao clicar, abre uma barra de busca expandida (como o Spotlight do Mac)

GitHub Actions — CI/CD
Automatizar testes e deploy. Todo Pull Request passa por verificação automática antes de ir para produção.
INFRA
Alta
⚙️ O que vai acontecer automaticamente
  • Ao abrir um PR: GitHub roda verificação de tipos (TypeScript), lint e build
  • Se qualquer coisa quebrar, o PR fica bloqueado com ❌ — ninguém merga código com erro
  • Se tudo passar, aparece ✅ verde — pode mergear com confiança
  • Ao mergear na main: deploy automático para o servidor de staging
  • Badge de status no README: mostrando que tá tudo certo
💡 Por que isso importa

Quando são 3 devs trabalhando ao mesmo tempo, é fácil o código de um quebrar o do outro sem perceber. O CI pega isso antes de ir para produção e evita a clássica situação de "funcionava na minha máquina".

Reviews na Página do Anime
Seção dedicada para ler o que a comunidade achou de um anime. Hoje só mostra o form e a nota agregada.
APIUI
Alta
🖥️ Como vai ser a seção de reviews
  • Seção logo abaixo do Pentagon Score na página do anime
  • Preview das 3 melhores reviews com card: avatar do usuário, nota visual, trecho do texto, data
  • Se a review tiver spoiler, o texto fica com blur — clique para revelar

Filtro por Gênero no Catálogo
Hoje o catálogo só tem busca por texto e filtro de status. Muita gente procura anime por gênero.
APIUI
Média
🖥️ Como vai funcionar
  • Chips clicáveis de gênero na página /anime: Ação · Romance · Comédia · Fantasia · etc.
  • Selecionar um chip filtra o grid instantaneamente (sem recarregar)
  • Múltiplos gêneros selecionáveis: mostrar animes que têm todos os gêneros selecionados

Testes Automatizados
Garantir que as partes mais importantes do sistema não quebrem quando alguém mexe no código.
API
Média
🧪 O que testar primeiro
  • Fórmula do Pentagon Score — a nota final deve bater exato com a fórmula (hype tem peso duplo)
  • Autenticação — login com senha errada deve retornar erro 401; token expirado deve ser bloqueado
  • Notificações sem duplicata — a mesma notificação não pode ser enviada duas vezes
  • Sync com isLocked — anime com isLocked=true não deve ter dados sobrescritos pelo sync
  • Hype XP — ação deve creditar a quantidade certa de XP
💡 Por que isso importa agora

Com 3 devs mexendo ao mesmo tempo, é fácil uma mudança quebrar algo que funcionava. Os testes são a rede de segurança. Não precisa de 100% de cobertura — focar nas regras de negócio que teriam o maior impacto se quebrassem.

📌 Nota

Jest já está configurado no projeto. Rodar com npm test -w @anihype/api. Começar pela fórmula do Pentagon Score — é a mais simples e mais importante de garantir.
